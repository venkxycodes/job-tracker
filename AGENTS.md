# Agent instructions

## Commit messages

Use `<verb>: <commit-message>` in commit messages. Use a concise imperative message after the colon.

Examples:
- `feat: add new job to tracker`
- `fix: preserve filters when editing a job`
- `chore: update dependencies`

Common verbs include `feat`, `fix`, `chore`, `docs`, `hotfix`, and `ci`.

## Working agreements

- Keep changes focused on the requested outcome and preserve existing behavior unless the request calls for a change.
- Follow the project's existing React, TypeScript, Firebase, and UI conventions.
- For interface work, prioritize the user's task, clear actions, accessible interaction, and complete loading, empty, success, and error states.
- Do not commit unless explicitly asked.
- Before finishing, summarize what changed and any checks run. Do not claim checks that were not run.
