# Ethics

Use when reviewing persuasive UX, conversion flows, pricing, signup, cancellation, consent, privacy, notifications, retention mechanics, or user autonomy.

## Core Principles

- Persuasion becomes dark UX when business goals override informed user intent.
- Ethical design preserves agency: clear information, fair defaults, easy refusal, easy reversal.
- Consent must be explicit, specific, and understandable.
- Costs, renewals, data use, consequences, and tradeoffs must appear before commitment.
- Scarcity, social proof, urgency, streaks, rewards, and loss aversion need truth and proportionality.
- Extra scrutiny applies to children, health, finance, privacy, accessibility, addiction risk, and other vulnerable contexts.

## Agent Checks

1. Does primary flow serve user goal, not only conversion metric?
2. Is decline, cancel, delete, unsubscribe, or skip as easy to find as accept/sign up?
3. Are opt-ins unselected by default unless user clearly requested them?
4. Are costs, renewals, data use, and consequences visible before commitment?
5. Are reject/skip labels neutral, not shameful or fear-based?
6. Are urgency, scarcity, ratings, testimonials, and activity counts truthful and verifiable?
7. Does design avoid hiding important details in low contrast, tiny text, or late steps?
8. Does UI avoid trapping attention with autoplay, infinite scroll, streak pressure, or variable rewards when user benefit is weak?
9. Are destructive or privacy-impacting actions reversible or clearly confirmed?
10. Would user likely choose same action if fully informed and unpressured?
11. Does persuasive element benefit user, not just owner?
12. Flag dark-pattern risks explicitly, even when requested UI may increase short-term metrics.

## Common Failure Modes

- Prechecked marketing or data-sharing consent.
- "No thanks, I hate saving money" style confirmshaming.
- Cancellation hidden behind support contact while signup is self-serve.
- Countdown or stock warning without truthful backing.
- Pricing card hides fees until checkout.
