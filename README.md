# Job tracker

A small React and TypeScript starter for tracking jobs during a search.

## Run locally

Requires Node.js 20.19+ or 22.12+.

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. Run `npm run build` for a production build and `npm run lint` for lint checks.

The starter lets you add jobs to an in-memory list. Entries reset on refresh. Firebase persistence is a future step; no Firebase credentials are needed to run this starter.
